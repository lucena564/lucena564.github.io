ImobiDesk

Internal purchase & sale proposal generator for Ondine Bezerra Imóveis

Proposal history with status, values, and quick open.

Local property catalog synced from the brokerage site.

ImobiDesk is an internal tool that turns property listings into polished purchase and sale proposals in minutes. Brokers pick a template, select a listing, fill buyer/seller and commercial terms, preview the document, and export a versioned PDF.

AI assists where it helps: Grok extracts party data from images or PDFs, and a Studio flow lets admins iterate on LaTeX templates with live PDF preview.

Stack

  • Vue 3 + Vite + Pinia
  • FastAPI + SQLAlchemy + Alembic + PostgreSQL
  • Docker Compose
  • LaTeX / XeLaTeX PDF generation
  • xAI Grok for extraction & template studio

Highlights

  • Guided proposal flow with drafts, preview, and immutable PDF versions
  • Property catalog sync from the public brokerage site
  • LaTeX (XeLaTeX) templates with Jinja placeholders and Grok Studio
  • Document AI extraction for buyer, seller, and commercial conditions
  • Auth with Argon2id, HttpOnly sessions, and CSRF on mutations
