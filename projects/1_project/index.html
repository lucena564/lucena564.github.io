IvyChat — AI Agent

Real-estate assistant powered by LLMs

I built Ivy for my mother, a real-estate broker: a WhatsApp-integrated AI assistant hosted on AWS microservices. It answers questions about Brazil’s Tenant Law (Lei do Inquilinato), mortgage options (Caixa, Banco do Brasil, Santander), and manages leads — when a client wants a visit, Ivy notifies the right brokers and triages the request.

Built in Python with Evolution API 2.0 on EC2. Stack highlights:

  • LangChain
  • LangGraph
  • Docker
  • Evolution API
  • API Gateway · SQS · EC2

AWS deployment

Technologies

  • AWS (EC2, SQS, API Gateway)
  • Python (Flask)
  • Webhook integration with Evolution API

Features

  • Smart assistant for property and financing questions
  • Bank APIs for credit conditions
  • Lead routing to the right brokers
