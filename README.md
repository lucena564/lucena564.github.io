# 🚀 Site Pessoal - Antônio Lucena

Bem-vindo ao meu site pessoal! Este projeto é um portfólio online desenvolvido com **Jekyll** e hospedado no **GitHub Pages**. Ele apresenta minha trajetória profissional, projetos desenvolvidos e formas de contato.

## 🔗 Acesse o site

Você pode visualizar o site acessando:

➡️ [lucena564.github.io](https://lucena564.github.io/)

## 📌 Sobre o Projeto

O site foi criado utilizando o tema [al-folio](https://github.com/alshedivat/al-folio), que fornece um design elegante e responsivo para exibição de portfólios acadêmicos e profissionais. Algumas das tecnologias e bibliotecas utilizadas incluem:

- **Jekyll** para geração de páginas estáticas;
- **Bootstrap 4** e **Material Design for Bootstrap** para estilização;
- **FontAwesome** e **Academicons** para ícones;
- **GitHub Pages** para hospedagem gratuita.

## 📂 Estrutura do Projeto

A estrutura principal do repositório é:
```
├── _includes/           # Componentes reutilizáveis do site
├── _layouts/            # Layouts base das páginas
├── _pages/              # Páginas individuais do site
├── _posts/              # Postagens do blog (se aplicável)
├── _sass/               # Estilos personalizados em SCSS
├── assets/              # Imagens, fontes e outros arquivos estáticos
├── _config.yml          # Configuração do Jekyll
├── index.md             # Página inicial
└── README.md            # Documentação do projeto
```

## 🚀 Como Rodar Localmente

Se você deseja rodar o site localmente para personalizações ou melhorias, siga estes passos:

1. **Clone o repositório**
   ```bash
   git clone https://github.com/lucena564/lucena564.github.io.git
   cd lucena564.github.io
   ```

2. **Instale o Jekyll e dependências** (certifique-se de ter o Ruby instalado):
   ```bash
   bundle install
   ```

3. **Inicie o servidor local**
   ```bash
   bundle exec jekyll serve
   ```

4. **Acesse o site localmente**
   Abra seu navegador e vá para `http://localhost:4000/`
